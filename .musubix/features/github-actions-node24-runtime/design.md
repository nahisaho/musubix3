# GitHub Actions Node.js 24 runtime design

## DES-GITHUB-ACTIONS-NODE24-RUNTIME-001: Reviewed action lock and offline validation
Responsibilities: Store one reviewed record for every external action reference used by the repository workflows; bind each record to repository, exact commit SHA, release tag, action kind, observed runtime, immutable source URL, reviewer, review date, crossed majors, and reviewed migration sources; parse all workflow `uses:` references; reject incomplete, duplicate, stale, unreferenced, or inconsistent lock data without network access.
Interfaces: `scripts/github-actions-lock.json` schema version 1 contains `actions[]`; every entry has `repository: string`, `sha: string`, `tag: string`, `kind: "javascript" | "composite" | "docker"`, `sourceUrl: string`, `reviewer: string`, `reviewedAt: YYYY-MM-DD`, and `crossedMajors: Array<{ major: number, migrationUrl: string }>`; `runtime: "node24"` is required only for `kind: "javascript"` and forbidden otherwise; root-level reviewer/date defaults are not supported; `tests/github-actions-node24-runtime.test.ts` loads the lock and `.github/workflows/{ci,release,npm-publish}.yml`; YAML parsing uses the existing `yaml` package; test diagnostics identify the workflow path, action reference, and invalid lock field.
Constraints: Every external non-local and non-`docker://` action has exactly one record; references use lowercase 40-character commit SHAs and comments equal the full recorded release tag byte-for-byte, such as `# v5.0.0`; JavaScript records require `runtime: "node24"`; `sourceUrl` is a commit-pinned `https://github.com/<repository>/blob/<sha>/action.yml` URL embedding the same SHA, while crossed-major migration URLs may use immutable release, comparison, commit, or pull-request URLs; "stale" means that the workflow repository/SHA/tag comment no longer matches its lock entry or that a lock entry has no workflow reference; the check is deterministic and never fetches live action content; the selected exact reviewed releases are checkout v5.1.0, setup-node v5.0.0, setup-python v6.3.0, setup-go v6.5.0, setup-java v5.7.0, upload-artifact v6.0.0, and download-artifact v7.0.0; each belongs to the smallest major with a reviewed Node.js 24 release compatible with current inputs, but runtime evidence always comes from `action.yml` at the selected pinned SHA rather than a release-note claim.
Requirements: REQ-GITHUB-ACTIONS-NODE24-RUNTIME-001 REQ-GITHUB-ACTIONS-NODE24-RUNTIME-002
ADRs: ADR-0035

## DES-GITHUB-ACTIONS-NODE24-RUNTIME-002: Protected workflow migration and release hand-off contract
Responsibilities: Replace action SHAs and version comments in `ci.yml`, `release.yml`, and `npm-publish.yml`; preserve protected workflow behavior; store the reviewed baseline provenance and protected-value snapshot; derive release artifact upload roots, download destinations, and consumer paths; verify release-assets and release-attestation resolve to the files consumed by attest, GitHub Release, and npm publish jobs.
Interfaces: `.github/workflows/ci.yml`; `.github/workflows/release.yml`; `.github/workflows/npm-publish.yml`; `tests/fixtures/github-actions-node24-runtime/baseline.json` containing baseline commit, workflow path, blob ID, source SHA-256, job/step order, triggers, permissions, conditions, environments, concurrency, matrices, action inputs, and protected commands; `.musubix/changes/CHANGE-0021.md` exposes `## Upstream-mandated input changes` with header `action | input | baseline | replacement | immutable upstream source`, ignores only the header and separator, treats zero data rows as no exceptions, and rejects malformed or duplicate data rows; `tests/github-actions-node24-runtime.test.ts` performs baseline, table-parser, package metadata, and artifact-contract assertions.
Constraints: No job or step is added, removed, or reordered; only action SHAs and accurate full-tag comments change unless a valid row is first added to CHANGE-0021's fixed-format upstream-mandated input table; tested Node versions, permissions, OIDC/provenance, environments, concurrency, triggers, conditions, and publication commands remain byte-semantically equivalent to the fixture; artifact checks compare resolved destination files rather than raw path strings; `package.json` must continue to omit `packageManager`, preventing setup-node v5's automatic package-manager cache in jobs without an explicit `cache` input, and the npm-publish workflow continues to run setup-node before any checkout so no workspace package manifest can enable automatic caching there; download-artifact's artifact-ID path change does not apply because all repository downloads select artifacts by explicit `name`.
Requirements: REQ-GITHUB-ACTIONS-NODE24-RUNTIME-001 REQ-GITHUB-ACTIONS-NODE24-RUNTIME-002
ADRs: ADR-0035
Depends-On: DES-GITHUB-ACTIONS-NODE24-RUNTIME-001

## DES-GITHUB-ACTIONS-NODE24-RUNTIME-003: Hosted runner policy and operational evidence
Responsibilities: Document the portability matrix and floating hosted-runner policy in English and Japanese; assert documentation and workflow runner labels agree; define the exact post-merge log check for the Node.js 20 action-runtime warning; retain release and npm-publish checks as mandatory evidence at the next publication.
Interfaces: `README.md`; `README-ja.md`; `tests/github-actions-node24-runtime.test.ts`; CHANGE-0021 verification records `gh run view <run-id> --log` and a literal search for `The following actions target Node.js 20`.
Constraints: Documentation distinguishes action implementation runtime from the Node.js versions tested by the project; `ubuntu-latest`, `windows-latest`, and `macos-latest` remain floating GitHub-hosted labels whose hosted runner version satisfies the Node.js 24 actions' minimum runner requirement of 2.327.1; an image migration requires toolchain, typecheck, build, tests, package, release preparation, provenance, and publication-control validation; no release or npm publication is triggered solely to manufacture evidence for this change.
Requirements: REQ-GITHUB-ACTIONS-NODE24-RUNTIME-001 REQ-GITHUB-ACTIONS-NODE24-RUNTIME-003
ADRs: ADR-0035
Depends-On: DES-GITHUB-ACTIONS-NODE24-RUNTIME-002
