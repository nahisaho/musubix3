# GitHub Actions project Node.js 24 design

## DES-GITHUB-ACTIONS-PROJECT-NODE24-001: Primary workflow runtime migration
Responsibilities: Move repository-owned primary workflow execution from Node.js 22 to Node.js 24 while preserving the Node.js 20 package compatibility floor and every unrelated workflow contract.
Interfaces: `.github/workflows/ci.yml` changes only the `core-portability` job name and setup-node value; `.github/workflows/release.yml` changes its three setup-node values; `.github/workflows/npm-publish.yml` changes its one setup-node value; `.github/workflows/dependency-audit.yml`, `native-adapters`, and `formal-solvers` remain Node.js 24; the CI-contract block in `scripts/check-npm-audit-remediation.mjs` gains `REQ-GITHUB-ACTIONS-PROJECT-NODE24-001`; `TEST-NPM-AUDIT-REMEDIATION-003` gains the matching `@verifies` link; `TEST-GITHUB-ACTIONS-PROJECT-NODE24-005` verifies the active-line contract and diagnostic wording.
Constraints: Normalize parsed YAML version scalars with `String(...)`; require exactly one Node.js 24 setup-node step in `core-portability`; parse current `release.yml` and `npm-publish.yml` and require all four setup-node values to normalize to `24`; retain `node-compatibility` as `[20, 24]`, `engines.node` as `>=20`, all commands, action pins, triggers, permissions, conditions, environments, concurrency, artifact paths, OIDC/provenance, and publication controls; scope npm-audit mutation edits to the `core-portability` job source slice before replacing its version or inserting a duplicate setup-node step.
Requirements: REQ-GITHUB-ACTIONS-PROJECT-NODE24-001 REQ-NPM-AUDIT-REMEDIATION-002
ADRs: ADR-0035 ADR-0036 ADR-0040

## DES-GITHUB-ACTIONS-PROJECT-NODE24-002: Protected workflow correspondence and provenance
Responsibilities: Extend deterministic protected-workflow validation with one exact-path CI exception and an offline immutable prior/current publishing-source comparison.
Interfaces: `CODE-GITHUB-ACTIONS-NODE24-RUNTIME-002` in `scripts/check-github-actions.mjs` gains `REQ-GITHUB-ACTIONS-PROJECT-NODE24-001`, `REQ-GITHUB-ACTIONS-PROJECT-NODE24-002`, and this design ID; `TEST-GITHUB-ACTIONS-PROJECT-NODE24-001`, `TEST-GITHUB-ACTIONS-PROJECT-NODE24-002`, and `TEST-GITHUB-ACTIONS-PROJECT-NODE24-004` in `tests/github-actions-node24-runtime.test.ts` gain matching trace links; each baseline fixture uses its copied path beneath `GITHUB_ACTIONS_WORKFLOW_ROOT` when present and otherwise the repository path; `tests/fixtures/github-actions-node24-runtime/baseline.json` remains the reviewed CI baseline; `tests/fixtures/release-asset-publishing/workflow-baseline.json` stores prior source/provenance and current digests.
Constraints: First positively require the current core job name and `String(...)`-normalized version, then copy the parsed CI document and copy the baseline document's scalar values verbatim into only `jobs.core-portability.name` and that job's setup-node `with.node-version` before the existing whole-document comparison; keep CHANGE-0021's input-change table unused. Embed fixed prior commit, blob IDs, prior SHA-256 values, and approved change `CHANGE-0047` in the checker; compare only fixture prior fields to prior literals; require each `priorSource` to end with one newline; compute SHA-256 and Git blob SHA-1 from its exact UTF-8 bytes without Git history; compare `sourceSha256` only with current source bytes; split prior/current sources on `\n`, require equal line counts, exactly three release and one npm-publish differing indices, and only same-indentation `node-version: 22` to `node-version: 24` pairs. Fixture identity/provenance failures use `WORKFLOW_REVIEWED_BASELINE`; a current workflow digest or prior/current line-diff mismatch uses `WORKFLOW_PROTECTED_DRIFT`. Historical human auditability uses the retained exact `priorSource`, blob IDs, and SHA-256 values after the source branch disappears; no permanent Git ref is required for deterministic verification.
Requirements: REQ-GITHUB-ACTIONS-NODE24-RUNTIME-002 REQ-GITHUB-ACTIONS-PROJECT-NODE24-001 REQ-GITHUB-ACTIONS-PROJECT-NODE24-002
ADRs: ADR-0040
Depends-On: DES-GITHUB-ACTIONS-PROJECT-NODE24-001

## DES-GITHUB-ACTIONS-PROJECT-NODE24-003: Documentation and operational evidence checker
Responsibilities: Keep bilingual runtime documentation exact and validate staged, completed, and deferred operational evidence without weakening the existing CHANGE-0021 evidence contract.
Interfaces: `CODE-GITHUB-ACTIONS-NODE24-RUNTIME-003` in `scripts/check-github-actions.mjs` retains runner/document policy and gains `REQ-GITHUB-ACTIONS-PROJECT-NODE24-003` plus this design ID; a new `CODE-GITHUB-ACTIONS-PROJECT-NODE24-EVIDENCE-001` annotates CHANGE-0047 evidence validation with the same requirement/design; `TEST-GITHUB-ACTIONS-PROJECT-NODE24-003` in `tests/github-actions-node24-runtime.test.ts` gains matching trace links; each README path uses `GITHUB_ACTIONS_PROJECT_NODE24_DOC_ROOT` when its copied file exists and otherwise the repository file; `README.md` and `README-ja.md` each own three exact raw single-line statements; `checkEvidence()` continues to validate CHANGE-0021 and separately validates production `.musubix/changes/CHANGE-0047.md`, with the exact-path `GITHUB_ACTIONS_PROJECT_NODE24_CHANGE_PATH` override available only for isolated fixtures.
Constraints: Require each CHANGE-0047 evidence anchor exactly once; emit `CHANGE_PROJECT_NODE24_EVIDENCE` messages that identify CHANGE-0047 and the failing anchor; isolated evidence tests provide both valid CHANGE-0021 and CHANGE-0047 fixture paths; parse front matter status; for non-completed status accept only the exact pending strings or completed grammar; require completed CI URL `https://github.com/nahisaho/musubix3/actions/runs/<digits>`, exact `success` core conclusions, and deferred completed values `<run-url>; Node.js 20 warning: absent`; when status is completed, reject pending post-merge values, malformed URLs, or non-success conclusions; allow release/npm-publish pending values until natural execution. Compare raw lines including leading whitespace and emit `PROJECT_NODE24_DOCUMENTATION` with the owning file and missing statement. `README.md` owns: `- Core CI covers Node 24 on Linux, Windows, and macOS, while the Linux compatibility matrix tests Node 20 and Node 24.`; `  The actions' Node.js 24 implementation runtime is independent of the Node.js 20/24 versions tested for this package.`; `Core CI runs on Node 24 across Linux, Windows, and macOS, while the Linux compatibility matrix tests Node 20 and Node 24.`. `README-ja.md` owns: `- Core CIはNode 24をLinux、Windows、macOSで実行し、LinuxではNode 20/24の互換性も検証します。`; `  Action 自体の Node.js 24 runtime は、package が検証する Node.js 20/24 とは別のものです。`; `Core CIはNode 24をLinux、Windows、macOSで実行し、Linuxのcompatibility matrixではNode 20とNode 24を検証します。`. Reflow preserves all adjacent packaging, native-adapter/formal-solver, hosted-runner-policy, and pack-smoke text; preserve `engines.node >=20`.
Requirements: REQ-GITHUB-ACTIONS-PROJECT-NODE24-003
ADRs: ADR-0040
Depends-On: DES-GITHUB-ACTIONS-PROJECT-NODE24-002
